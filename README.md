## 🎵 ¿Qué es Sonido Celestial Radio?

Sonido Celestial Radio es una aplicación móvil que te permite escuchar nuestra emisora en vivo desde cualquier lugar. Con una interfaz intuitiva y funciones optimizadas para una experiencia auditiva inolvidable.

### ✨ Características principales

- 🎧 **Streaming en vivo** - Escucha la radio 24/7
- 📱 **Interfaz intuitiva** - Fácil de usar para todos
- 🔄 **Reproducción en segundo plano** - Sigue escuchando mientras usas otras apps
- 📶 **Bajo consumo de datos** - Optimizado para ahorrar tu plan de datos
- 🎨 **Diseño atractivo** - Con la identidad visual de Sonido Celestial
